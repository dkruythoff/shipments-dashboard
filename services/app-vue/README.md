# Shipment dashboard: Front end app (Vue)

The shipment dashboard Vue front end. Uses components from the styleguide-vue library in the form of a `@shipments/ui` package, and connects with the API service.

## Stack
- [Vue](https://vuejs.org)
- [TypeScript](https://typescriptlang.org)
- [Vite](https://vite.dev)
- [Vue Router](https://router.vuejs.org)

## Environment
- `VITE_API_BASE` — The URL of the API service. Defaults to `//localhost:8000` in development.
